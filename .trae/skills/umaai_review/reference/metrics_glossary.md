# 口径与术语速查（metrics_glossary）

> digest.json 各字段的确切含义。与 `.trae/documents/replay_review.md` 同源；
> bin 侧实现以 `crates/umaai_review` 为准。

## 运气分体系

| 术语 | 含义 |
|---|---|
| `T(n)` / `t_n_display` | 第 n 个决策点的「局面期望终局分」估计（display 口径 = raw + (78 − turn) × mcts_turn_bonus；turn_bonus 是 MCTS 预期的每回合平均运气增长，实际非线性——增长慢于预期时曲线持续阴跌，总口径：不进则退） |
| `t_n_raw` | 反推的 raw 值（bonus 剥离后） |
| `turn_delta` | T(n+1) − T(n)，是**局面期望变化**，不等于本回合属性增量 |
| 回合合计 Δ | 同回合多段（RamenSelect / Train / RegionSelect）Δ 之和——**基本观察单位**；吃面段正 + 训练段继续正 = 好局面 |
| `total_luck` / `total_luck_end` | 累计运气分（终局值）；`< -2000`（≈方差量级）仍可判「这局运气差」（保守线）。旧局包（2026-10-01 前录制，无 keyEvents）曲线系统性略偏低——brief §0 的录制年代注记会自动标注 |
| `flagged_turns` | 位置标记（年界 [24,48,72] 前 2 至后 1 回合 / 继承 [30,54] / RMJ playing_state 46·48 自动检测 / **开局 t2-3 第 1 年地区选择**）。跨年假跳 2026-10 修复后已基本消除——标记位置的跳变大多是真实结算 / 继承落地 / 选择本身的变化，**按性质归因**，不当连续损益读；仅再出现一增一减配对式大幅账面波动时降级；**turn 72 双属性**：既标记也算进超级拉面统计（份量实打实） |
| 自选比赛期限波动 | **>8000 的运气波动通常与自选比赛期限有关**（用户口径）：窗口截止前若仍未达标，MCTS 对「将育成失败」的状态大幅低估 → 运气分骤降；补赛达标后回升。净变≈0，**不影响最终运气**，但「自选比赛极限达标」是值得关注的操作。判据：回合合计 Δ ≤ −8000，其后 3 回合内回升 ≥ +8000 且净变 ≤ 幅度的 25%；骤降/回升两回合都进 `flagged_turns`（reason=`free_race_deadline_swing`），并在 `schedule.notes` 出一行注记。**注意年界窗口可能同时命中且归因有误**（game3099 t22/t23 既标 `year_boundary(24)` 又是本波动——真实原因是自选期限） |
| 学技能标记 | **技能点只减不增——减少就一定是玩家学了技能**（没有别的减少途径），故不设运气分门槛，逐回合查技能点（回合末口径）、减少即标（reason=`skill_learned(-Npt)`）。**为什么重要**：花掉技能点后 AI 的期望终局分把「未花掉的技能点」计入价值 → 运气分下降，但**不是真实运气下降**。实测 game1429：t34 花掉 1030 点、同回合运气分 −2678。与马娘专属判据常同时出现（见 `uma_specific.md`） |

## 阶段与决策

| 术语 | 含义 |
|---|---|
| 决策点快照 | **行动前**局面；行动结果体现在下一个 turn 更大的快照 |
| 锚点 | 每回合最后一条 `decision_kind=train` 的 calc 行（Train 阶段是最终执行；不吃面路径的 RamenSelect 行即最终项） |
| 同回合 seq 递增 | 阶段推进，**不是**行动结果 |
| `chain_len` | 同 file 连续行数（链式决策长度；在线留空，bin 推断回填） |
| skip 行 | stage=Begin 的不派发快照（event / RMJ / 数据不全 / 超拉丢包），见 `coverage.skip.by_reason` |
| `raceHistory` | 只记**跑赢**的比赛；输掉的比赛需用 schedule 兜底判「比赛」 |

## 执行推断（execution）

| 项 | 口径 |
|---|---|
| 比赛判定 | raceHistory +1（跑赢）**或锚点回合 ∈ 必赛回合 ∪ URA 73/75/77** |
| 训练判定 | **先判训练、再用体力形态否证**。目标维：**推荐维优先**——它是最大增量，**或**自身增量达 **+20**（`TRAIN_ATTR_MIN`；事件给属性的量级通常低于此），否则取最大增量。成立条件：目标维增量 ≥ **分年分段阈值**（第 1 年用训练基础值表最低主维，实测 7；第 2 年起 12）。体力仅作**否证**：体力 ≥ +25 且目标维未达 +20 → 判休息（休息 + 事件小额属性）；反过来目标维达 +20 时即使体力回升仍判训练（智训练不耗体力，事件可同时回体） |
| 对应候选（`alt_candidate`） | 偏离一选时实际动作命中的候选编号（如 `#2 力训练`）——**偏离主要是选了 2-3 选**，有编号＝换了个候选、不必然是不听建议；`—`＝候选外操作（推断失准或表外动作） |
| 休息判定 | 体力 ≥ +25（表值休息 +30~+70；容忍事件小额属性） |
| 继承窗口 | 锚点 29/53 的窗口含继承落地 → 实际动作标注「继承混合」、不参与一致率（无法从数据剥离） |
| 一致率 | game6234 实测 89.3%（75 可比 / 8 偏离）；AIRedirector 局仅作校验 |

## 剧本机制常量

| 常量 | 值 |
|---|---|
| 年份边界 | [24, 48, 72] |
| 继承回合 | [30, 54]（与年界错开 6 回合的独立事件） |
| 超级拉面期 | turn ≥ 72；开局自动加体力与心情（干劲），掉状态有兜底，恢复建议不必要求 72 前手动补 |
| 继承参考值 | `Σ(extra_count[0..5]) + 126`（game_config `[config_override]`，只比五维不含 PT） |

## 分身彩圈（clones）

| 术语 | 含义 |
|---|---|
| 新增分身 | 吃面前出现 ≤1 位 → 吃面后 ≥2 位（卡 × 回合事件） |
| 分身落位 | 末快照位置 − 本体位；absent 卡 = 全部末位 |
| **彩圈** | 分身落位 == cardType（**本体占的得意位不算**；任意位口径的 52% 命中率大部分是本体占位假象，实测真实落位仅 2/31；分身主要价值是提高训练效果，玩家已知，叙事不解释） |
| 彩圈来源 | `luck` = 吃面前本体在场（随机有效增加 → 好运气）；`strategy` = 本体缺席被规则带入（规则有效增加 → 好策略） |
| 彩圈吃到 | **地区分身**：`region_per_turn` 明细的 `used` 字段（当回合实际训练命中彩圈位 → 吃到收益；未考虑分身存续期的后续训练）。**超级拉面分身**：机制保证落位，没吃到不算亏 |
| 地区分身 / 超级拉面分身 | 地区分身 = turn<72（**彩圈为 0 = 坏局面，须明确写出**，见本文「地区分身彩圈为 0」节；落位随机、无可操作空间）；超级拉面分身 = turn≥72（**只统计训练卡**——友人 cardType=5 无得意位；机制保证 100% 落得意位的旧说法基于任意位口径） |

### 地区分身彩圈为 0 = 明显的坏局面（用户拍板）

- **观测**：`clones.region` 里 `new_clones` 有几十张，但 `rainbow_clones` / `trained_clones` 为 **0**。
- **判据**：**这是坏局面，一般都会产生一些彩圈**——一张都不落属于成色很差的一局，是**实打实的坏运气**。
  要**明确写出来**，不能因为「A 类判据待定义、纯观测」就略过不提。
- **叙事**：如实报数（新增 N 张 / 落位 M 次 / 彩圈 0），定性为坏运气。**落位是随机的，没有可操作空间**，
  不给玩家「下次注意」这类落点。
- **实测**：game1430 新增 30 张、32 次落位、彩圈 0（`region_per_turn` 逐回合 `rainbow_positions` 全为空）。

### 彩圈没吃到 ≠ 失误（用户拍板，2026-10-09）

- **判据**：brief §5.3 没吃到的行**已带原因鉴别**——取当回合 Train 决策的候选评分对比
  （候选评分已含分身加成——AI 派发时的快照带分身人头）：
  - 实际动作候选评分 ≥ 彩圈位训练候选 → 「选了更强训练，正常取舍」；
  - 彩圈位训练评分更高却没选 → **真错过**（叙事可点出：该回合 X 训练评分更高却选了 Y）；
  - 彩圈位训练不在候选表 → 不具竞争力，按推荐取舍同样正常；实际动作候选外 → 只报事实。
- **叙事**：没吃到先读行内鉴别再定性——**正常取舍不当失误数落**；只有真错过的行
  才值得展开。彩圈落位本身随机（无可操作空间）的口径不变。

### 地区选择 = 固定运气波动，与属性无关（用户拍板）

- **范围**：`region_select` 决策——开局 t1 第 1 年地区选择，以及 t23 / t47 等 RegionSelect 阶段。
- **判据**：这类选择带来的期望跳变是**固定运气波动**，**和属性增长无关**。
- **禁止的表述**：不得写成「把地区选择当成补属性的机会」「用地区选择补某维」这类操作建议——
  它不是可以通过选择去调节属性的杠杆，给了会误导玩家。
- **归因**：按程序性波动处理（与 `flagged_turns` 的 `region_select(y1)` 同一类），叙事里降级或不展开。

## 评分与赛程

| 项 | 口径 |
|---|---|
| `training`（训练画像） | 逐年「训练次数（推断实际动作计数）/ 五维净增（年段差分，含事件 / 继承 / 比赛）/ 运气归属（回合合计 Δ 计入当回合实际训练维；自选 swing 与学技能回合剔除归 `luck_program`，非训练回合归 `luck_other`）」。**增长先后顺序**（如先耐后速：卡少的维靠质量 / 时机反超）与「涨运气的训练主要类型」从这里读 |
| `final_score` | **AI 端按实际终局五维与技能点的估算**（`Uma::calc_score`：五维查表 + PT 折算 + 切者/小切 PT 项加成 + Hint 折算）——**略高于小黑板与实际分数**（PT 折算高于实际买技能的得分），不含已学技能分。来源按 `meta.final_source` 分流：`final_frame` = 真机终局帧（育成结束·点技能前，含全部结局事件）；`last_snapshot` = 末快照估算，**缺结局事件 ≈ -2700，相对再偏低** |
| `is_qiezhe` / `is_xiao_qie` | 切者（能人，状态 7）×1.1 / 小切（勤勉好学，状态 40）×1.04，只乘 PT 项（互斥）；终局评分已计入（终局帧无该标志，按末快照代入）。**获得切者的回合** `timeline.is_qiezhe` 由 false→true，T(n) 有 PT 项 ×1.1 量级的期望跳升——真实好运，不当程序性波动 |
| `rank` | 与 rank.csv 同表换算 |
| 五维显示值 | digest `timeline.five_status_display`（bin 已按 (real − 1200) / 2 + 1200 换算，real > 1200 时）；叙事报显示值，评分与运气分不受此换算影响 |
| 必赛 / 自选 | `schedule.mandatory_turns`（umaDB races）；自选 = raceHistory − 必赛（区间内）；URA 73/75/77 是剧本固定赛不算自选 |
| 不可做 | 评价「该选哪场比赛」（比赛池不在 gamedata） |

## 五维偏低与补维建议（用户拍板）

- **判据**：复盘**不得仅因某维终局数值低就建议玩家「加强该维训练」**——「能训练的
  属性」依赖玩家携带的卡组，卡组没有携带的维（如一张力 / 根卡都没带）终局偏低是
  **客观事实**，不是操作或运气问题。
- **正确的补维路径**（要给提升建议时只从这三条里给）：
  1. **加强对应主属性的训练**：练速可以补力、练耐可以补根、练根可以补速 / 力；
  2. **选用副属性更强的支援卡**：如想补根，选拉根能力更强的耐卡；
  3. **改进种马质量**：争取继承更多的对应属性。
- **叙事**：低维结合卡组构成解释（卡少的维偏低是结构性事实，一句带过即可）；
  触顶维照实报，但低维不输出「下次多练该维」这类直接建议。

## 残余偏差与旧局包注记（读运气分必看）

1. **RMJ 结算结果按「每年成功」假设补齐**（重放路径无从知道真机实际成败）→ 真机若失败，该年起期望整体偏高。年界跳变的「双重结算 / region_select 计入运气」两类旧 bug 已分别于 2026-10-01 / 2026-10-03 修复，年界读数照 `flagged_turns` 降级即可
2. **旧局包按录制年代带历史偏差**（brief §0 criteria 按局包内容自动标注）：
   - 2026-10-01 前录制（快照无 keyEvents）：支援卡连续事件进度未对齐 → 整条曲线系统性略偏低；
   - 2026-10-03 前录制：turn 2 含链式推进漏加 NPC 的 +1300 量级假跳；
   - 2026-10-07 前录制：turn 71→72 含 URA 赛后加成丢失的 −1000 量级程序性假跳
3. 「掉干劲后未主动恢复」曾是「模拟高估事件回复」导致的决策倾向（旧 bug ②），新录制已缓解；检查项仍观测该行为，作观察项与改进方向

## 归因口径（用户拍板）

- **目标赛未跑赢、超拉期连亏、掉干劲本身 = 运气，不是操作**：输赛是随机结果，
  掉干劲由数据外事件带来（输赛不掉干劲，快照无事件明细列待查），超拉期估值走低是随机落地差；叙事归运气，不当坏手法表述
- **地区分身彩圈为 0 也是坏运气**（一般都会有些），须明确写出
- **地区选择是固定运气波动、与属性无关**，不得当作补属性的操作手段
  （以上两条判据均见本文「分身彩圈」节；`uma_specific.md` 只留马娘专属条目）
- **五维偏低不得给「练该维」的直接建议**——能练的维依赖卡组，未携带的维偏低是客观
  事实；补维只走三条路：练对应主属性（练速补力 / 练耐补根 / 练根补速力）、换副属性
  更强的支援卡、改进种马继承（判据见本文「五维偏低与补维建议」节）
- 「掉干劲后未主动恢复」是偏差②导致的决策倾向，作观察项与改进方向
- 比赛叙事口径：全胜是基本操作不提战绩，输赛才展开（用户拍板）
