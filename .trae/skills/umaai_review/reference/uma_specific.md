# 马娘专属判据（模型层处理）

> **为什么单独放这里**：这类判据依赖具体马娘的赛程 / 对手 / 事件，无法用通用规则表达，
> 也不该硬编码进 Rust（写错会污染所有局的结论）。**由模型层在归因时判读**。
>
> Rust 侧只提供通用事实（运气分、技能点、赛程、比赛结果、flagged 标记），不做专属判定。
>
> **新增条目按「马娘 / 回合 / 观测 / 判据 / 解释」五要素追加**，并注明实测局号。

## 通用前置：先分清「运气分下降」的几种成因

专属判据常与下列通用成因纠缠，判读前先排除：

| 成因 | 判据 | 归因 |
|---|---|---|
| 学技能 | **技能点变少**（技能点只减不增，减少必是学技能）→ `skill_learned(-Npt)` 标记 | 程序性，不是真实运气下降 |
| 自选比赛期限 | 幅度 >8000 的骤降 + 随后回升（`free_race_deadline_swing` 标记） | 程序性，净变≈0 |
| 年界 / 继承 / RMJ / 开局地区选择 | `year_boundary` / `inherit` / `rmj_*` / `region_select(y1)` 标记 | 程序性，降级或跳过 |
| 旧局包假跳 | brief §0 录制年代注记（2026-10-03 前 turn 2 / 2026-10-07 前 turn 71→72） | 程序性，已修复的口径偏差 |

**以上都排除后**，剩下的负向波动才考虑是否为真实运气损益或专属判据。

> **正向跳变另查**：`timeline.is_qiezhe` 由 false→true 的回合 = 获得切者（能人），T(n) 有 PT 项 ×1.1 量级的期望跳升——**真实好运**，不当程序性波动。

> **通用判据不放本文件**：地区分身彩圈为 0、地区选择为固定运气波动等条目对**所有马娘通用**，
> 已移入 `metrics_glossary.md`（口径速查）。本文件**只留依赖具体马娘赛程 / 对手 / 事件的条目**。

## 神威启示

- **t33 强敌**（实测局：game1429，已用真实数据核对）
  - **判据**：**只要 t33 这场输了，就一定是对手很强**——不需要附加条件
    （玩家学不学技能都一样）。数据面：`schedule.notes` 出现「未跑赢的必赛回合: [33]」，
    或 findings 出现 `mandatory_race_not_won t33`。
  - **解释**：该回合的对手强度超出当前面板，输赛是**对手强**，不是操作失误、也不是运气差。
  - **叙事**：如实说明对手强度，**不数落玩家**（安抚不出口）。
  - **实测关联**：game1429 该局 t33 未跑赢后，t34 玩家花掉 **1030** 技能点学技能
    （`skill_learned(-1030pt)` 标记），同回合运气分骤降 **−2678**。若叙事看到这个下降，
    应按「学技能 + 强敌」解释，**不要读成倒霉**。
